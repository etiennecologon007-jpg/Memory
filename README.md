# 🧠 Jeu de Memory

Jeu de Memory classique développé en JavaScript, HTML et CSS dans le cadre de ma formation en BUT Informatique.

Le but du jeu est de retrouver toutes les paires de cartes identiques en un minimum de coups et en le plus court temps possible.

## ✨ Fonctionnalités

- Génération aléatoire des cartes à chaque partie
- Mécanique de retournement des cartes
- Vérification automatique des paires
- Suivi du temps de jeu en direct
- Comptage des coups joués
- Détection automatique de la victoire
- Bouton pour relancer une partie
- Interface simple et intuitive

## 🎯 Règles du jeu

1. Cliquez sur une carte pour la révéler.
2. Cliquez sur une seconde carte.
3. Si les deux cartes sont identiques, elles restent visibles.
4. Si les cartes sont différentes, elles se retournent face cachée après un court instant.
5. Le jeu est terminé lorsque toutes les paires ont été trouvées.

## 🚀 Lancer le projet

### Option 1 : ouvrir directement dans le navigateur

1. Téléchargez ou clonez ce dépôt.
2. Ouvrez le dossier du projet.
3. Ouvrez le fichier `index.html` dans votre navigateur préféré.
